# Knowledge Directory

Store source Markdown knowledge documents in this folder (`knowledge/**/*.md`).

- Use nested folders when useful (for example: `runbooks/`, `architecture/`, `notes/`).
- Keep paths stable so links and references remain valid.
- Prefer descriptive frontmatter (`title`, `tags`) to improve retrieval quality.
- Use clear heading structure so section-level chunking remains precise.
- See the root [README](../README.md) for indexing lifecycle, MCP setup, and run commands.
